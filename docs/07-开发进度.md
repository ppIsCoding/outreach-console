## 2. 已完成明细

### 2.1 前端

- 设计 token 体系（暖白画布 + 深青主色 + 状态色），全部走 CSS 变量
- 侧栏 / 顶栏 / 页面骨架
- 概览区：3 张主指标卡（趋势面积图、环形仪表、执行中任务实时进度）+ 3 项次指标
- 任务列表：6 状态 Tab（带计数）、关键词防抖、话术 / 时间筛选、URL 同步
- 表格：数值右对齐 + 等宽数字、进度条、状态标签、行内操作按状态机启用
- 分页 / 跨页多选 / 批量暂停与终止
- 新建任务抽屉：3 步向导 + 字段级校验 + 预估耗时 + 风险提示
- 任务详情抽屉：结果分布、意向分布、状态流转时间线、快捷操作
- 乐观更新 + 失败回滚（`onMutate` 快照 / `onError` 回滚 / `onSettled` 重取）
- WebSocket 进度同步（mock 用本地定时器，http 用原生 WS + 指数退避重连）
- 五种演示状态切换（正常 / 加载 / 空 / 筛选空 / 失败 / 无权限）
- 可访问性：reka-ui 焦点陷阱、Esc 关闭、`aria-*`、原生 checkbox、`prefers-reduced-motion`
- 自托管字体（不依赖 Google Fonts）

### 2.2 后端

- 统一响应 `{code,message,data,traceId}` 与全局异常处理
- 任务 CRUD + 状态机 + 乐观锁
- 分页查询、状态计数、概览统计
- WebSocket `/ws/tasks` 推送进度
- `@Scheduled` 模拟外呼推进并写通话结果
- H2 默认零配置 + MySQL profile
- Swagger（springdoc）
- 10 个单元测试

## 6. 接续开发指引

```bash
# 前端（mock，无需后端）
cd web && npm install && npm run dev

# 后端
cd server && mvn spring-boot:run

# 前端（真实接口，需先启动后端）
cd web && npm run dev:api
```

关键文件：

| 关注点 | 文件 |
|---|---|
| 接口契约 | `web/src/api/types.ts` |
| mock 数据与场景 | `web/src/api/mock/db.ts`、`seed.ts` |
| 乐观更新 | `web/src/composables/useTasks.ts` |
| 状态机（前端只读副本） | `web/src/lib/task-status.ts` |
| 状态机（后端权威） | `server/.../service/TaskStateMachine.java` |
| 设计 token | `web/src/styles/main.css` |

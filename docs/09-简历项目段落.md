## 2. 分点式（面试/作品集用）

**智能语音外呼任务看板** — Vue 3 + TypeScript + Spring Boot 3 + MyBatis-Plus

- **页面还原**：基于设计 token 搭建看板，含 3 张主指标卡（趋势图 / 环形仪表 / 实时进度）
  与 9 列数据表；数值列统一等宽右对齐，长文本省略并提供 Tooltip。
- **状态完整性**：覆盖加载（骨架屏）、空数据、筛选无结果、请求失败、无权限 5 种状态；
  统计与列表支持独立失败降级，单区块重试不影响整页。
- **交互与一致性**：筛选条件全部同步 URL，刷新与分享可还原现场；
  暂停 / 恢复采用乐观更新，失败回滚并提示；破坏性操作二次确认并说明影响范围。
- **实时能力**：WebSocket 推送执行中任务进度，断线指数退避重连；
  后端 `@Scheduled` 模拟外呼调度器，按并发数推进任务并写入通话结果。
- **后端设计**：状态机集中管理 8 种状态流转，非法流转返回 409；
  状态更新带版本号实现乐观锁；统一响应体、字段级参数校验与全局异常处理。
- **工程化**：ESLint 0 告警、Prettier、TypeScript 严格模式、25 个 Vitest 用例；
  前端支持 mock / 真实接口双模式，评审无需环境即可运行。

## 5. 如果你的背景不同，这样调整

| 你的情况 | 调整方式 |
|---|---|
| 没有实习经历 | 把「个人项目」写实，重点放**完成度与工程化**，不要虚构团队协作 |
| 项目只有这一个 | 加一个课程设计或小工具，哪怕简单，证明持续动手 |
| 更偏前端 | 删掉后端两点，补充：组件抽象、设计系统、性能优化、可访问性 |
| 更偏后端 | 弱化视觉描述，补充：索引设计、分页策略、并发控制、接口幂等 |
| 时间紧张 | 只用「一段式」，面试时再展开 |

## 6. 面试时的 30 秒自述模板

> 「这个项目是外呼业务的运营看板。我主要解决三个问题：
> 一是**信息密度**——一屏内要看到概览、筛选和任务，所以做了 3 主 3 次的层级；
> 二是**状态完整性**——除了题目要求的三种状态，我补了筛选空和无权限，
> 并且让统计和列表可以独立失败；
> 三是**AI 协作的可控性**——我记录了 9 个 AI 产出有问题的案例，
> 比如乐观锁、0 除、排序参数语义反了，这些是编译器发现不了的。
> 技术上前后端都做了，前端 Vue 3，后端 Spring Boot，默认 mock 模式方便评审直接打开。」

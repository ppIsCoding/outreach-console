# 数据模型与接口

> 前端类型定义：`web/src/api/types.ts`
> 后端实现与完整接口说明：`server/README.md`、`http://localhost:8080/swagger-ui/index.html`

---

## 1. 核心实体

### Task（外呼任务）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | `T20261103001` |
| name | string | 2–30 字，同一创建人下唯一 |
| scriptId / scriptName | string | 话术模板 |
| lineId / lineName | string | 外呼线路 |
| status | enum | DRAFT / SCHEDULED / RUNNING / PAUSED / COMPLETED / FAILED / TERMINATED / CANCELLED |
| priority | enum | NORMAL / HIGH |
| totalContacts | int | 名单总数，1–50000 |
| calledCount | int | 已呼数 |
| connectedCount | int | 接通数 |
| intentCount | int | 意向客户数 |
| totalDurationSec | int | 累计通话秒数 |
| concurrency | int | 并发数 1–50 |
| retryLimit | int | 重呼次数 0–3 |
| retryIntervalMin | int | 重呼间隔 5–1440 分钟 |
| callWindow | string | `09:00-20:00` |
| scheduledAt / startedAt / finishedAt | datetime | `yyyy-MM-dd HH:mm:ss` |
| creatorName | string | 创建人 |
| version | int | 乐观锁版本号 |

### 关联表

| 表 | 用途 |
|---|---|
| `script` | 话术模板（名称 / 行业 / 版本） |
| `call_line` | 外呼线路（供应商 / 总并发 / 已占用） |
| `call_result` | 单次通话结果（号码 / 结果 / 时长 / 意向等级） |
| `task_event` | 状态流转事件（用于详情时间线） |

## 2. 派生指标

| 指标 | 公式 | 边界 |
|---|---|---|
| 进度 | `calledCount / totalContacts` | 名单为 0 → 0 |
| 接通率 | `connectedCount / calledCount` | 已呼为 0 → `—` |
| 意向率 | `intentCount / connectedCount` | 接通为 0 → `—` |
| 平均通话时长 | `totalDurationSec / connectedCount` | 接通为 0 → `—` |
| 预估耗时 | `剩余号码 × 45s / 并发数` | 并发最小按 1 处理 |

> 前端统一在 `web/src/lib/utils.ts` 里计算，保证列表、详情、概览三处口径一致。

## 3. 接口清单

统一前缀 `/api/v1`，响应体：

```json
{ "code": 0, "message": "ok", "data": {}, "traceId": "a1b2c3" }
```

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/dashboard/summary` | 概览指标（含环比、7 日趋势、并发占用） |
| GET | `/tasks` | 分页查询 |
| GET | `/tasks/stats` | 各状态计数 |
| GET | `/tasks/{id}` | 详情（含事件、结果分布、可执行动作） |
| POST | `/tasks` | 创建 |
| PATCH | `/tasks/{id}/status` | 状态流转 `{action, version}` |
| POST | `/tasks/{id}/duplicate` | 复制为草稿 |
| DELETE | `/tasks/{id}` | 删除（仅草稿） |
| GET | `/tasks/{id}/results` | 通话结果分页 |
| GET | `/meta/scripts` | 话术模板 |
| GET | `/meta/lines` | 线路与并发占用 |
| WS | `/ws/tasks` | 进度推送 |

### 查询参数

`status`、`keyword`、`scriptId`、`dateRange`（today/7d/30d）、`page`（从 1 开始）、`size`（默认 10，上限 100）、`sort`（`createdAt,desc`）。

### 错误码

| code | HTTP | 含义 |
|---|---|---|
| 40001 | 400 | 参数校验失败，`data` 内含字段级错误 |
| 40401 | 404 | 任务不存在 |
| 40901 | 409 | 状态冲突 / 非法流转 / 乐观锁失败 |
| 50000 | 500 | 服务端异常 |

## 4. 前后端字段映射

后端 DTO 与前端领域模型的命名不同，由 `web/src/api/http-mappers.ts` 统一转换：

| 前端 | 后端 |
|---|---|
| `todayCalls` | `todayCalledCount` |
| `todayCallsDelta` | `todayCalledCountChangeRate` |
| `connectRateBaseline` | `connectRateBenchmark` |
| `intentCount` | `intentCustomerCount` |
| `range` | `dateRange` |
| `stats: StatusCount[]` | `stats: { all, draft, running, ... }` |
| `callWindowStart / End` | `callWindow: "09:00-20:00"` |

**为什么保留映射层**：前端 mock 与后端实现可以独立演进；字段调整只改一个文件，组件层零改动。

## 5. 状态机

```
DRAFT ──SUBMIT──> SCHEDULED ──START──> RUNNING ──PAUSE──> PAUSED
                      │                  │  ↑              │
                   CANCEL              TERMINATE  RESUME    TERMINATE
                      ↓                  ↓  └──────────────┘
                  CANCELLED          TERMINATED
```

- 权威实现：`server/.../service/TaskStateMachine.java`
- 前端只读副本：`web/src/lib/task-status.ts`（仅用于按钮禁用，最终以服务端校验为准）
- 非法流转返回 `40901`

## 6. 实时推送

```json
{ "type": "task.progress", "taskId": "T20261103001", "payload": { "calledCount": 1713, "connectedCount": 530, "status": "RUNNING" } }
```

- 连接后客户端发送 `{"type":"subscribe","taskIds":[]}`
- 断线指数退避重连（1s → 2s → 4s，上限 30s）
- 前端直接把 payload 写入 TanStack Query 缓存，避免整表重取

> 目的：证明视觉决策是「有依据的选择」，而不是凭感觉堆样式。

## 2. 采纳与不采纳

| Skill 建议 | 决策 | 理由 |
|---|---|---|
| 配色：Primary `#1E40AF`（蓝）/ Background `#F8FAFC` | **不采纳** | 蓝 + 冷灰是「AI 生成的通用后台」最典型的组合，辨识度为零。改用深青 `#0B6B5F`（信号/连接语义，贴合语音外呼）+ 暖白画布 `#F6F5F1`，在同类作品里一眼可辨。 |
| 强调色：Amber `#D97706` | **采纳并调整** | 保留琥珀作为第二序列（图表、警示），但压深到 `#C2841A`，避免与主色抢注意力。 |
| 字体：Fira Sans + Fira Code | **不采纳** | Fira 的中文回退质量差，中英混排会明显割裂。改用 **IBM Plex Sans + IBM Plex Mono**：Plex 自带工程感与人文细节，且与 PingFang / 思源黑体的字面比例更协调；等宽数字保证表格列对齐。 |
| Style：Data-Dense Dashboard | **采纳** | 与「运营看板」高度匹配。落实为 8px 栅格、56px 行高、卡片内边距 20px。 |
| Density 8/10 | **采纳** | 一屏内完成「看概览 → 筛状态 → 处置任务」，避免滚动疲劳。 |
| Motion 3/10（Subtle） | **采纳并进一步收敛** | 运营后台不需要滚动入场动画，会干扰读数。只保留：进度条 500ms、抽屉 260ms、Toast 200ms、数字变化。全部受 `prefers-reduced-motion` 约束。 |
| 反模式：Ornate design | **采纳** | 无渐变背景、无玻璃拟态堆叠、无装饰性插画；仅用 1px 描边 + 极轻阴影建立层次。 |
| 反模式：No filtering | **采纳** | 状态 Tab（带计数）+ 关键词 + 话术 + 时间范围，且全部同步 URL。 |
| 图标：禁用 emoji，使用 SVG | **采纳** | 全站 Lucide 线性图标，统一 1.6 描边。 |

## 3. 对比度审计（WCAG 2.1 相对亮度计算）

初版 token 存在两处不达标，已修正：

| 用途 | 前景 | 背景 | 修正前 | 修正后 | 结论 |
|---|---|---|---|---|---|
| 正文 | `#16191F` | `#FFFFFF` | 16.9:1 | 16.9:1 | AAA |
| 次要正文 | `#5B6270` | `#FFFFFF` | 6.0:1 | 6.0:1 | AA |
| 辅助说明（12px） | `#8B919E` → `#6E7683` | `#FFFFFF` | **3.2:1 ✗** | 4.6:1 | AA |
| 占位符 / 装饰 | `#B4B9C2` → `#868D99` | `#FFFFFF` | 2.0:1 ✗ | 3.3:1 | 仅限非必要信息 |
| 主色文字 | `#0B6B5F` | `#FFFFFF` | 6.4:1 | 6.4:1 | AA |
| 主色文字（标签） | `#0B6B5F` | `#E6F0ED` | 5.3:1 | 5.3:1 | AA |
| 危险 | `#B4472F` | `#FFFFFF` | 5.4:1 | 5.4:1 | AA |
| 警示（标签） | `#B7791F` → `#8A5A12` | `#FAF0DC` | **3.2:1 ✗** | 5.2:1 | AA |
| 成功（标签） | `#2E7D5B` → `#276B4D` | `#E7F2EC` | 4.4:1 ✗ | 5.0:1 | AA |
| 信息（标签） | `#2F5FA8` | `#E9EFF8` | 5.5:1 | 5.5:1 | AA |
| 侧栏导航 | `#8E97A6` | `#12161C` | 6.0:1 | 6.0:1 | AA |

> 计算方式：sRGB → 线性化 → 相对亮度 `L` → `(L1+0.05)/(L2+0.05)`。数值取两位小数，允许 ±0.1 误差。
> `--color-ink4` 明确约定：**只用于占位符、禁用态、图表刻度等非必要信息**，正文与关键标签一律使用 `ink2/ink3`。

## 4. 已落地的 UX 规则

| 规则（来自 skill） | 落地位置 |
|---|---|
| 表格窄屏用横向滚动，不撑破布局 | 表格容器 `overflow-x-auto` + `min-width` |
| 批量操作（勾选列 + 操作条） | 表头全选、跨页选中、底部批量条 |
| 焦点可见，弹层内同样可见 | 全局 `:focus-visible` + reka-ui Dialog 焦点陷阱 |
| 焦点不被遮挡 | 抽屉底部操作区固定，内容区独立滚动；`scroll-padding` |
| 紧凑控件要有语义 | 状态筛选用 `button` + `aria-selected`；开关用 `role="switch"` |
| 错误信息靠近字段 | 表单字段下方 inline 提示 + `aria-invalid` + `aria-describedby` |
| 不用 emoji 当图标 | 全站 Lucide SVG |
| 尊重 reduced-motion | `@media (prefers-reduced-motion: reduce)` 全局降级 |
| 数据表格数字对齐 | 所有数值列 `font-variant-numeric: tabular-nums` |
| 加载不引发布局跳动 | 骨架屏与真实内容同高 |

## 5. 有意偏离规范的地方

| 规范 | 偏离 | 原因 |
|---|---|---|
| 触控目标 ≥ 44×44px | 桌面端按钮 28–34px | 这是桌面运营后台，主输入为鼠标 + 键盘；44px 会显著降低信息密度。已保留 8px 最小间距与可见焦点，并保证键盘可达。若后续做移动端，需单独适配。 |
| 基础字号 16px | 正文 13–14px | B 端数据密集型界面的行业惯例；标题 22/30px 保持层级。可读性通过行高 1.5 与对比度补偿。 |
| 滚动入场动画 | 不使用 | 运营人员高频刷新，入场动画会拖慢每次读数；仅保留状态变化的微动效。 |

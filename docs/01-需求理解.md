# 智能语音外呼任务看板 · 需求理解

> 版本 v1.0 ｜ 对应考核题目：智能语音外呼任务看板页面
> 本文档用于对齐「做什么、为什么这么做、做到什么程度算完成」。

---

## 1. 业务背景

智能语音外呼（AI Outbound）是用机器人替代人工完成批量电话触达的业务，典型场景包括：

- **新客回访**：注册未下单用户的首轮触达
- **活动通知**：促销、续费、到期提醒
- **存量唤醒**：沉默用户召回
- **满意度回访**：服务完成后的 NPS 调研

业务链路：

```
配置话术 → 导入名单 → 创建外呼任务 → 调度执行 → 实时监控 → 通话结果分析 → 意向客户跟进
```

运营人员每天的核心动作是：**建任务、盯进度、处理异常、看转化**。
本页面服务于链路中的「创建 → 监控 → 处置」环节。

## 2. 用户与场景

| 角色 | 关注点 | 高频操作 |
|---|---|---|
| **外呼运营专员** | 任务是否正常跑、有没有卡住、今天呼了多少 | 建任务、看进度、暂停/恢复、处理异常 |
| **团队主管** | 整体接通率、意向转化、任务排期是否合理 | 看统计、对比任务、终止低效任务 |
| 系统管理员（本期不覆盖） | 线路、并发、话术版本 | — |

**核心用户故事**

1. 作为运营，我需要在**一屏内**看到今日外呼概览，判断整体是否健康。
2. 作为运营，我需要按状态快速筛出「执行中」和「异常」的任务，优先处理问题。
3. 作为运营，我需要 3 步内创建一个外呼任务，并在提交前看到预估耗时，避免配置错误。
4. 作为运营，我需要在不刷新页面的情况下看到执行中任务的进度增长。
5. 作为运营，当接口失败时，我需要知道**哪一块**失败了，并能单独重试，而不是整页白屏。

## 4. 页面详细需求

### 4.1 概览区

**主指标卡（3 张，视觉权重递减）**

| 指标 | 口径 | 辅助信息 |
|---|---|---|
| 今日外呼量 | 今日 00:00 起已拨出通话数 | 环比昨日百分比 + 近 7 日面积趋势图 |
| 接通率 | 接通数 / 已拨出数 | 环形进度 + 行业基准对比（虚线） |
| 执行中任务 | status = RUNNING 的任务数 | 前 3 个任务的名称 + 实时进度条 |

**次要指标（无卡片，横向分隔）**

意向客户数、平均通话时长、任务完成率。

> 设计取舍：6 张同规格卡片会让页面变成"仪表盘模板"，视觉上没有主次。
> 因此改为「3 主 + 3 次」，用尺寸和留白建立层级。

**交互**

- 点击「执行中任务」卡 → 状态 Tab 自动切到「执行中」
- 数据加载中显示骨架屏，高度与真实内容一致，避免布局跳动
- 单张卡片接口失败 → 该卡降级显示 `--` 与重试图标，**不影响其他卡片和列表**

### 4.2 状态筛选

以 Tab 形式呈现，**每个 Tab 带数量**：

```
全部 24 ｜ 执行中 3 ｜ 待执行 3 ｜ 已暂停 2 ｜ 已完成 11 ｜ 异常 2
```

- 计数来自后端聚合，不随前端分页变化
- 计数为 0 时 Tab 置灰但仍可点击（点击后进入空态）
- 筛选条件全部同步到 URL：`?status=running&q=618&page=2`
- 「重置」按钮仅在存在非默认筛选时出现
- 筛选切换时保留滚动位置，列表区独立 loading（不整页闪）

**其他筛选项**

- 关键词：匹配任务名称 / 任务 ID，300ms 防抖
- 话术模板：下拉单选
- 时间范围：今日 / 近 7 天 / 近 30 天 / 自定义

### 4.3 任务列表

| 列 | 说明 |
|---|---|
| 复选框 | 支持跨页选择（以 ID 集合维护） |
| 任务名称 | 超长省略 + Tooltip；副行显示任务 ID |
| 话术模板 | 名称 + 版本号 |
| 名单量 | 千分位 |
| 进度 | 已呼 / 总数 + 进度条；非执行中状态显示最终进度 |
| 接通率 | 百分比，低于 20% 用警示色 |
| 状态 | 彩色标签，执行中带脉冲点 |
| 计划/创建时间 | 相对时间 + Tooltip 显示绝对时间 |
| 操作 | 详情 / 暂停·恢复 / 复制 / 删除（按状态机禁用） |

**行级规则**

- 执行中的行，进度条每 2 秒推进（WebSocket 推送）
- 操作按钮按状态机动态渲染，不可用状态**置灰并给出原因 Tooltip**，而不是直接隐藏
- 删除、终止需二次确认，弹窗内说明影响范围（如「将中断 1,240 个未拨号码」）

**批量操作**

- 仅当选中项中存在可执行该操作的任务时才启用
- 部分成功时提示「成功 2 条，失败 1 条」，并列出失败原因

**分页**

- 默认 10 条/页，可选 10 / 20 / 50
- 删除当前页最后一条时自动回退上一页
- 总数变化时校正页码，避免停留在空页

### 4.4 新建任务（抽屉 + 3 步向导）

选择抽屉而非居中弹窗：字段较多，抽屉可保留背景上下文，且不会在窄屏被压缩。

**Step 1 · 基础信息**

- 任务名称（必填，2–30 字，同一创建人下不可重名）
- 话术模板（必填，下拉带行业标签与版本）
- 外呼线路（必填，展示当前占用并发 / 总并发）
- 优先级（普通 / 高）

**Step 2 · 呼叫对象**

- 名单来源：上传文件 / 选择号码池 / 按标签圈选
- 展示预估号码数、去重后数量
- 去重开关（默认开）、过滤近 7 天已呼号码（默认开）
- 号码数为 0 时阻止进入下一步，并给出具体原因

**Step 3 · 外呼策略**

- 执行方式：立即 / 定时（时间需晚于当前 5 分钟）/ 周期
- 并发数（1–50，且不超过线路剩余并发）
- 未接通重呼：0–3 次，间隔 5–1440 分钟
- 呼叫时段（默认 09:00–20:00，开始须早于结束）

**Step 4 · 确认**

- 汇总所有配置
- **预估耗时**：`名单数 ÷ (并发 × 平均通话 45s)`
- 提示风险项，如「当前时段剩余 2 小时，预计无法今日完成」

**通用规则**

- 步骤间可回退，已填数据保留
- 未完成当前步时「下一步」禁用，并提示缺失项
- 提交中按钮 loading + 全表单禁用，防重复提交
- 提交失败保留表单内容，错误定位到具体字段
- 关闭抽屉时若有未保存内容，二次确认

### 4.5 任务详情抽屉

- 基础信息 + 当前状态 + 进度
- 状态流转时间线（创建 → 调度 → 开始 → 暂停 → 完成）
- 通话结果分布（接通 / 未接 / 空号 / 拒接 / 关机）
- 意向等级分布（A/B/C/D）
- 快捷操作：暂停 / 恢复 / 终止 / 复制

## 5. 任务状态机

```
                    ┌──────────── 取消 ────────────┐
                    ↓                              │
  ┌───────┐  提交  ┌──────────┐  到点   ┌─────────┐ │
  │ 草稿   │ ────> │ 待执行    │ ─────> │ 执行中   │ │
  │ DRAFT │       │ SCHEDULED│        │ RUNNING │ │
  └───┬───┘       └────┬─────┘        └────┬────┘ │
      │                │                   │      │
   删除│                │取消            暂停│恢复   │
      ↓                ↓                   ↓ ↑    │
     ✕            ┌──────────┐        ┌─────────┐ │
                  │ 已取消    │        │ 已暂停   │ │
                  │CANCELLED │        │ PAUSED  │ │
                  └──────────┘        └────┬────┘ │
                                           │终止   │
  执行中 ──全部拨完──> 已完成 COMPLETED     ↓      │
  执行中 ──异常率>30%──> 异常 FAILED     ┌─────────┐
                                        │ 已终止   │
                                        │TERMINATED│
                                        └─────────┘
```

| 当前状态 | 允许动作 | 目标状态 | 前置条件 |
|---|---|---|---|
| 草稿 | 编辑 / 删除 / 提交 | 待执行 | 配置完整 |
| 待执行 | 取消 / 立即执行 | 已取消 / 执行中 | — |
| 执行中 | 暂停 / 终止 | 已暂停 / 已终止 | — |
| 已暂停 | 恢复 / 终止 | 执行中 / 已终止 | 线路并发可用 |
| 已完成 | 复制 | — | — |
| 异常 / 已终止 / 已取消 | 复制 / 删除 | — | — |

**并发控制**：状态变更接口需带 `version` 字段做乐观锁，冲突返回 `40901`，前端提示「任务状态已被他人修改，请刷新」。

## 6. 状态与异常处理矩阵

| 场景 | 表现 | 恢复方式 |
|---|---|---|
| 首屏加载 | 骨架屏（卡片 + 表格行），保持布局尺寸 | 自动 |
| 列表局部加载 | 表格区域半透明 + 顶部细进度条，保留旧数据 | 自动 |
| 空数据（无任何任务） | 插画 + 「还没有外呼任务」+ 新建按钮 | 新建 |
| 空数据（筛选无结果） | 文案「没有符合条件的任务」+ 清除筛选 | 清除筛选 |
| 请求失败 | 区块内错误卡片 + 错误码 + 重试按钮 | 重试 |
| 统计失败 / 列表成功 | 卡片显示 `--`，列表正常 | 单卡重试 |
| 列表失败 / 统计成功 | 表格区错误态，概览保留 | 重试 |
| 401 未登录 | 跳转登录，回跳原地址 | 登录 |
| 403 无权限 | 空状态「无访问权限」+ 联系管理员 | — |
| 404 任务不存在 | 抽屉内提示「任务已被删除」+ 关闭 | 关闭 |
| 409 状态冲突 | Toast「状态已变更」+ 自动刷新该行 | 自动 |
| 慢网络（>3s） | 显示「加载较慢，请稍候」+ 取消按钮 | 取消 |
| 提交中 | 按钮 loading，表单禁用 | — |
| 乐观更新失败 | 回滚 UI + Toast 说明原因 | 自动 |
| 网络断开 | 顶部横幅「网络已断开，正在重连」 | 自动重连 |

## 7. 字段字典（核心）

### Task

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 任务 ID，如 `T20261103001` |
| name | string | 2–30 字 |
| scriptId / scriptName | string | 话术模板 |
| lineId / lineName | string | 外呼线路 |
| status | enum | DRAFT / SCHEDULED / RUNNING / PAUSED / COMPLETED / FAILED / TERMINATED / CANCELLED |
| priority | enum | NORMAL / HIGH |
| totalContacts | int | 名单总数 |
| calledCount | int | 已呼数 |
| connectedCount | int | 接通数 |
| intentCount | int | 意向客户数 |
| totalDurationSec | int | 累计通话秒数 |
| concurrency | int | 并发数 1–50 |
| retryLimit | int | 重呼次数 0–3 |
| retryIntervalMin | int | 重呼间隔 5–1440 |
| callWindow | string | 如 `09:00-20:00` |
| scheduledAt | datetime | 计划执行时间 |
| startedAt / finishedAt | datetime | — |
| creatorName | string | — |
| createdAt / updatedAt | datetime | — |
| version | int | 乐观锁 |

### 派生指标

| 指标 | 公式 |
|---|---|
| 进度 | `calledCount / totalContacts` |
| 接通率 | `connectedCount / calledCount`（calledCount = 0 时为 `--`） |
| 意向率 | `intentCount / connectedCount` |
| 平均通话时长 | `totalDurationSec / connectedCount` |
| 预估耗时 | `(totalContacts - calledCount) × 45s / concurrency` |

## 8. 验收标准

**功能**

- [ ] 6 个状态 Tab 均可筛选，计数正确
- [ ] 关键词 + 话术 + 时间组合筛选生效，条件同步 URL
- [ ] 新建任务 3 步向导可完整走通，校验生效，提交后列表出现新任务
- [ ] 执行中任务进度通过 WebSocket 实时更新
- [ ] 暂停 / 恢复 / 终止 / 复制 / 删除均可用，且符合状态机
- [ ] 删除与终止有二次确认，并说明影响范围
- [ ] 分页、批量选择、跨页选择正确

**状态**

- [ ] 加载态为骨架屏，非全屏转圈
- [ ] 两种空态文案不同
- [ ] 错误态可单独重试，不清空已有数据
- [ ] 统计与列表可独立失败
- [ ] 表单校验、提交中、乐观更新回滚均生效

**质量**

- [ ] 键盘可完成主要操作（Tab / Enter / Esc）
- [ ] 焦点可见，弹层有焦点陷阱
- [ ] 1440 / 1280 / 1024 三档宽度无横向溢出
- [ ] 控制台无报错、无警告
- [ ] Lighthouse 可访问性 ≥ 90

## 9. 本期范围与不做的事

**做**

- 任务看板完整闭环（查、筛、建、控）
- 真实 Spring Boot 接口 + 实时进度推送
- 全状态覆盖与可演示的状态切换器

**不做（明确说明，避免范围蔓延）**

| 不做 | 原因 |
|---|---|
| 真实拨号 / 对接语音网关 | 需要运营商资质与线路资源 |
| 话术可视化编辑器 | 独立产品模块，与本题无关 |
| 完整 RBAC 权限体系 | 仅做前端入口级控制，接口预留 |
| 多租户 | 单租户演示足够 |
| 文件解析（真实 Excel 导入） | 用模拟上传 + 预估条数替代 |

> 明确「不做什么」与「做什么」同等重要：它决定了 4 天内能交付的质量上限。

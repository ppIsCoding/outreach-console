## 5. 面试可能被追问的问题

| 问题 | 回答要点 |
|---|---|
| 为什么默认用 mock，不直接连后端？ | 评审零成本打开；同时保留了 `dev:api` 真实联调，两者共用同一套类型与映射层。 |
| 乐观更新失败怎么处理？ | `onMutate` 先存快照并改缓存 → `onError` 用快照回滚 → `onSettled` 重新拉取，保证最终一致。 |
| 状态机为什么放后端？ | 前端只做按钮禁用提示，真正的合法性必须由服务端裁决，否则可被绕过。 |
| 数据量到 10 万条怎么办？ | 后端分页 + 索引；前端虚拟滚动；筛选走服务端；必要时改游标分页避免深翻页。 |
| 怎么保证 AI 生成的代码质量？ | 先定类型契约，再生成实现；固定 Review Checklist；对状态、并发、边界逐条验证。 |
| 你觉得自己这个作品最大的不足？ | 没有移动端适配；话术版本号后端未返回；Redis 与消息队列只了解未实践。 |
| 为什么用 reka-ui 而不是 Element Plus？ | 需要无皮肤的组件以完全控制视觉；同时直接获得焦点陷阱与 ARIA 支持，不必自己实现。 |
